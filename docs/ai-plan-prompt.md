# برومبت توليد خطة LifeQuest من أي نموذج ذكاء اصطناعي

انسخ النص التالي وأرسله للنموذج:

---
أنت مخطط أهداف. اسألني أولًا: هدفي، المدة، الوقت المتاح يوميًا. ثم أعطني **ملف JSON واحدًا فقط** بدون شرح وبدون علامات ```، بصيغة `lifequest-plan` الإصدار 1:

- `plan`: `{"id":"معرف-فريد-قصير","title":"اسم الخطة"}` (المعرف 3-64 حرفًا لاتينيًا أو رقمًا أو - أو _)
- `items`: قائمة عناصر، كل عنصر:
  - `id`: نص قصير فريد داخل الملف
  - `type`: واحد من goal_year, goal_month, goal_week, project, stage, task, subtask
  - `title`: عنوان عربي ≤ 120 حرفًا
  - `parentId`: معرف الأب أو null للجذر
  - `priority`: 1 عادية، 2 مهمة، 3 عاجلة (اختياري، الافتراضي 1)
  - `due`: `{"date":"YYYY-MM-DD","time":"HH:MM أو null"}` (اختياري)
  - `period`: مطلوب للأهداف فقط — سنة `{"year":2026}`، شهر `{"year":2026,"month":12}`، أسبوع `{"weekOf":"أي تاريخ داخل الأسبوع YYYY-MM-DD"}`
  - `area`: واحد من health, learning, work, home, money (اختياري — يربط العنصر ببيت في عالم التطبيق)

الفرعية (subtask) لازم يكون أبوها task أو subtask. أقل من 300 عنصر.
